# Информационная система салона красоты "Нефертити"

Одностраничный сайт с веб-интерфейсом, регистрацией клиентов, онлайн-записью с контролем занятости мастеров и админ-дашбордом.

## Стек
- PHP 8 + MySQL (PDO)
- Чистый HTML/CSS/JS без фреймворков
- Chart.js для диаграммы доходов администратора

## Запуск локально
1. Создайте базу и загрузите структуру/демо-данные:
   ```bash
   mysql -u root -p < db/init.sql
   ```
2. Настройте подключение в `config.php` (при необходимости измените логин/пароль). 
3. Разместите проект в корне вашего веб-сервера (например, Apache/Nginx + PHP-FPM) и откройте `http://localhost/index.php`.

## Демо-данные
- Администратор: `admin@nefertiti.ru` / пароль `admin123`
- Справочник услуг и мастеров уже заполнен популярными позициями, цены указаны в рублях.

## Функциональность
- Регистрация и авторизация клиентов
- Онлайн-запись с календарем и проверкой занятых слотов мастеров
- Личный кабинет с перечнем записей и их статусами
- Админ-режим: просмотр актуальных записей, управление справочниками клиентов/мастеров/услуг (через API), диаграмма доходов по месяцам, отмена записей (PATCH `/api/appointments.php`).

## Архив проекта
Готовый архив теперь собирается локально, чтобы не блокировать загрузку или Pull Request'ы.

Создать файл `nefertiti_site.zip` можно командой:

```bash
bash scripts/package.sh
```

Скрипт положит архив в корень проекта; сам zip игнорируется Git, чтобы не мешать репозиторию.
